# Header primogem

`primogem.png` is the original Genshin Impact item icon (item ID 201), downloaded
from https://enka.network/ui/UI_ItemIcon_201.png. Artwork belongs to HoYoverse.
The 64 × 64 transparent PNG is served locally. A CSS glint plays every six seconds
and respects the system's reduced-motion setting.

The SELFwishes lettering uses Philosopher Bold by Jovanny Lemonad, downloaded from
https://github.com/google/fonts/tree/main/ofl/philosopher and served locally under
`/fonts/philosopher/`. Its SIL Open Font License is bundled beside the font.
This is a complementary fantasy-style typeface, not the original Genshin font.
